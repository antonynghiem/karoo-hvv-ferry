🚀 TO GET STARTED (3 STEPS):

1. ADD GITHUB CREDENTIALS to gradle.properties:
   
   gpr.user=YOUR_GITHUB_USERNAME
   gpr.key=YOUR_GITHUB_TOKEN

2. BUILD THE PROJECT:
   
   ./gradlew assembleDebug

3. INSTALL ON KAROO:
   
   adb install app/build/outputs/apk/debug/app-debug.apk
